Wanted Features
===============

This page lists new portals and new features for existing portals that the
major desktop environments (GNOME, KDE) agree should be added. It serves as a
shared reference for contributors looking for impactful work and for desktop
developers coordinating on new interfaces.

Items on this list have rough consensus between desktop environments but do not
yet have a finalized interface. Contributors interested in working on any of
these are encouraged to open a
`discussion <https://github.com/flatpak/xdg-desktop-portal/discussions>`__
to coordinate the design.

New portals from this list will typically go through the
:doc:`experimental portals <experimental-portals>` process before being
promoted to stable.

New Portals
-----------

**Credentials**
   A portal for FIDO2 and passkey operations.

**Audio**
   A portal for audio device access and management.

**Network**
   A portal for network configuration and management.

**VPN**
   A portal for VPN configuration and management.

New Features for Existing Portals
---------------------------------

None yet.
